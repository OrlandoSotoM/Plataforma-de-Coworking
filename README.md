# CoworkSpace

Plataforma web de coworking desarrollada utilizando Python y Django.

## Descripción

CoworkSpace es una plataforma orientada a la gestión de espacios
de coworking. El proyecto permitirá posteriormente consultar
espacios, disponibilidad y realizar reservas.

## Tecnologías

- Python
- Django
- Git
- GitHub

## Instalación

Crear ambiente virtual:

python -m venv .venv

Activar ambiente virtual:

.venv\Scripts\activate

Instalar dependencias:

pip install -r requirements.txt

Ejecutar proyecto:

python manage.py runserver
